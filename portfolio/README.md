# Portfolio: single-page site

Juan Castelblanco's portfolio, aimed at backend Java / Spring Boot roles.

- One file: `index.html`. No build step, no dependencies (only Google Fonts).
- Includes light/dark mode, project filters, an interactive sample API explorer and a role-fit table.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy on Vercel
New Project → import this repo → set **Root Directory** to `portfolio` → Framework preset **Other** → Deploy.
